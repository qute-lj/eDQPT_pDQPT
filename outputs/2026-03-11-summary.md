# 2026-03-11 Run Summary

## Commands used

```bash
julia scripts/reproduce_dqpt_prl_2021.jl all --steps 40 --dt 0.05 --output-prefix medium --vumps-maxiter 40 --vumps-tol 1e-8
julia scripts/reproduce_dqpt_prl_2021.jl ising --steps 90 --dt 0.02 --output-prefix refine --vumps-maxiter 60 --vumps-tol 1e-10 --bond-dim 16 --grow-steps 40 --grow-by 1
```

## Key qualitative observations

- The refined Ising run shows its strongest early rate-function peak at `t = 1.16`, close to the textbook TFIM DQPT estimate `t* ≈ 1.175`.
- At that Ising peak, the mean entanglement entropy is only `0.474`, while the local order parameter remains sizable (`mz ≈ 0.506`).
- In the XXZ N\'eel protocol, the largest rate peak in the `medium` run occurs at `t = 1.55` with entropy already at `0.820`.
- By the final simulated time `t = 2.0`, the XXZ entropy reaches `1.070` while the staggered magnetization is almost gone (`staggered_mz ≈ -0.102`).

## Interpretation

These runs support the qualitative split emphasized in the 2021 PRL:

- Ising baseline: strong dynamical feature appears while the local order parameter is still appreciable and entanglement is moderate.
- XXZ N\'eel protocol: strong dynamical feature is accompanied by substantially larger entanglement growth and rapid loss of staggered order.

## Caveat

This is a qualitative reproduction in local MPSKit, not a claim of figure-by-figure numerical identity with the published PRL and supplement.
